About this build

An independently implemented community rebuild for experimenting with new features and quality-of-life improvements.

Your local arena

This build has its own real-time battle mechanics, 1,025 species, three saved teams, six visual arenas, and sixteen local challenge stages. It approximates the arena experience through independently written code. The original game’s proprietary source and story narrative are separate.

Your teams and progress stay in this browser, with save export and import in Settings. Online opens the official game because its server currently rejects direct access from the tested GitHub Pages domain.
