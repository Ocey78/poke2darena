Release date & updates

This community build and the original game have separate development histories.

Community build · 0.1.0

The first local version includes 1,025 species, three saved teams, six visual arenas, three CPU difficulties, and sixteen local challenge stages. Battle mechanics and arena artwork were created for this build.

Local saves can be exported and imported through Settings. Online opens the official game for multiplayer. Direct access to its server from a tested GitHub Pages domain returned a rejection.

Selected original game updates

  • November 6, 2026

    Collection & save improvements

    Card packs and the Pokedex expanded progression. Save codes gained a main-menu shortcut, move editing became easier to find, and active Pokemon gained passive ultimate charge.

  • November 5, 2026

    Mega Evolution in battle

    The game added in-battle Mega Evolution, refreshed battle finishes, and a new arrangement for mobile move buttons.

  • November 4, 2026

    Arena Run

    A six-floor challenge introduced consecutive team battles with carried health and upgrades between victories.
